# CTF Writeups

Structured writeups for Capture The Flag challenges solved during cybersecurity practice and competitions.

## Purpose

This repository records reproducible methodologies, not just final flags. Each writeup should explain the challenge context, the reasoning behind the solution, useful commands or code, and lessons that can be reused in future work.

## Categories

Writeups are organized by challenge category:

- `web/`
- `reverse-engineering/`
- `cryptography/`
- `forensics/`
- `pwn/`
- `osint/`
- `misc/`

## Writeup workflow

1. Copy `TEMPLATE.md` into the appropriate category.
2. Use a descriptive filename such as `web/ctf-name-challenge.md`.
3. Remove placeholders and include only verified observations.
4. Redact flags, credentials, personal data, and challenge information that should not be public.

## Security and ethics

Use the techniques documented here only on systems and challenges where you have explicit authorization. Do not publish live credentials, private data, or undisclosed vulnerabilities.

## Current status

The repository is intentionally initialized without fabricated challenges or solutions. New writeups will be added as they are completed and verified.
